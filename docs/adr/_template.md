# NNNN — Short, Decision-Focused Title

Status: Proposed | Accepted | Deprecated
Date: YYYY-MM-DD

## Context

Why does this decision exist? What problem does it solve? What was the
situation that forced this decision? (~2–5 sentences.)

## Decision

What is the change being proposed or the decision being made? Be concrete —
name the files/approaches. (~2–5 sentences.)

## Consequences

- Positive: what becomes easier or better?
- Negative / trade-offs: what becomes harder, or what did we give up?
- Follow-ups: what should happen next, if anything?

---

Note for agents: keep these short and concrete. If the reasoning already
lives in a code comment or `CONTRIBUTING.md`, reference it instead of
copying it.
